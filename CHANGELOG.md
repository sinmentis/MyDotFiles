# Changelog

All notable changes to the Copilot plugin are documented here.

## [0.1.0] - 2026-07-14

- Package the repository as `shunbox`.
- Add the `sinmentis` Copilot CLI marketplace.
- Move personal skills to the root-level `skills/` directory.
- Add plugin validation and synchronized version tooling.
- Migrate the dotfiles installer from a direct skills symlink to marketplace installation.
- Preserve machine-local MCP configuration during Copilot setup.
